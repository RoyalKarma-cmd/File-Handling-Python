# Python Expense Tracker

This is a beginner-friendly Expense Tracker project built using Python.

## Features
- Add expense name
- Add expense amount
- Store data permanently in a text file
- Append new expenses without deleting old data

## Concepts Used
- File Handling
- Write Mode
- Append Mode
- User Input
- String Concatenation

## How It Works
1. User enters expense name
2. User enters expense amount
3. Program stores data inside a text file
4. Data is saved permanently

## Example Output

Food - 200
Travel - 350
Coffee - 50
